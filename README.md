# 📧 Spam Email Detection using Machine Learning

This project is a **Spam Email/SMS Detection System** built using **Python** and **Machine Learning**.  
It classifies messages as either **Spam** or **Ham (Not Spam)** using the **Naive Bayes algorithm**.

---

## 🚀 Project Overview
The main goal of this project is to automatically detect spam messages by analyzing text features.  
We use Natural Language Processing (NLP) techniques and a trained model to classify each message.

---

## 🧠 Algorithms and Libraries Used
- **Algorithm:** Multinomial Naive Bayes  
- **Libraries Used:**
  - `pandas` – data loading and preprocessing  
  - `scikit-learn` – model training and evaluation  
  - `TfidfVectorizer` – text feature extraction
